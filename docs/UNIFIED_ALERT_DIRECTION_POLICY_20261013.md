# 3시트 통합감시 알림 방향 — 최종 사용자 결정 (2026-10-13 14:04 KST)

- 기술적 판단은 모든 종목에 동일한 `/unified-scan` 공통 엔진 사용. 세 시트는 **출처 목록**일 뿐이다.
- **HELD (현재 실제 보유):** 매수조짐 / 매수확인 / 하락조짐 / 하락확인 / 손절 / OBV15 등 **양방향 알림**.
- **ETF (보유하지 않은 관심 ETF):** `BUY_SETUP`, `BUY_CONFIRMED`만 이메일 발송. 하락/매도준비/시장급락/OBV위험은 발송하지 않음.
- **YOUTUBE (아직 보유하지 않은 언급종목):** `BUY_SETUP`, `BUY_CONFIRMED`만 이메일 발송. 하락/매도준비/손절/OBV위험은 발송하지 않음.
- **중복 티커:** `sources`에 `HELD`가 있으면 보유종목으로 판단해 **양방향**, 그렇지 않으면 **상승만**. 보유수량 업데이트 시 해당 시트 등록을 정본으로 삼는다.
- **코스피·코스닥 방향:** 상승일 때 매수 후보에 +1 보정, 하락일 때 보수적(-1) 매수 판단. 시장 자체가 하락했다는 별도 이메일은 보내지 않는다.
- **인버스:** 인버스 자체 기술적 상승일 때만 매수조짐·확인 이메일 발송. 시장 하락은 인버스 매수 판단의 유리한 시장 보정값일 뿐 독립 하락경보는 아니다.
- 매수 후보는 45분봉과 키움 실시간 조건을 그대로 충족해야 한다. 시장 보정으로 미확인 매수 후보를 확정으로 올리지 않는다.
- 하락·기타 이벤트는 `UNIFIED_DECISIONS` 기술·복기 기록에 남길 수 있지만 메일로는 내보내지 않는다.
- 실제 원본 기술지표 수식·종목 목록·기존 보유종목 경고·자동주문을 변경하지 않는다.

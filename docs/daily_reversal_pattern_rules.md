# 일봉 추세전환 8패턴 자동화 규칙 v1

> 목적: 단독 매수·매도 신호가 아니라 기존 Pullback/ATR/Freshness/수급/45분/JEV 판단의 SHADOW 보조근거.
>
> 원전 규칙: 사용자가 제공한 「박재훈의 투자농장 - 100조 운용역이 신입 펀드매니저에게 가르쳤던 차트 패턴 8가지」 요약.
> 아래 수치화 기준 중 '장대/단봉/현저한 갭/확연히'는 자동화를 위해 추가한 엔지니어링 정의이며 영상의 직접 수치가 아니다.

## 공통 선행추세

| 구분 | 자동화 조건 |
|---|---|
| 상승반전 4종 | 패턴 1일차 직전까지 SMA3가 5회 연속 하락 |
| 하락반전 4종 | 패턴 1일차 직전까지 SMA3가 5회 연속 상승 |
| 데이터 | 완성된 일봉만 사용. 장중 미완성 당일봉은 제외 |
| 장대봉 | 몸통 >= max(최근 20일 몸통 중앙값 × 1.25, ATR14 × 0.45) |
| 단봉 | 몸통 <= min(최근 20일 몸통 중앙값 × 0.75, ATR14 × 0.45) |
| 유효 갭 | ATR14 × 0.15 이상 |
| Star 비도지 | 몸통 > ATR14 × 0.03 |
| '확연히' 확인폭 | ATR14 × 0.15 이상 |

| BULL | BULL_HARAMI_CONFIRMED | 상승 잉태 확인형 | 1일차 장대음봉, 2일차 단봉이 1일차 몸통 안, 3일차 장대양봉 종가 > 1일차 시가 |
| BULL | BULL_ENGULFING_CONFIRMED | 상승 장악 확인형 | 1일차 단봉 음봉, 2일차 낮은 시가의 장대양봉이 1일차 몸통 장악, 3일차 장대양봉 종가 > 2일차 종가 |
| BULL | MORNING_STAR | 샛별형 | 1일차 장대음봉, 2일차 유효 갭하락 단봉·비도지, 3일차 갭상승 양봉 종가 >= 1일차 몸통 50% |

## 운용 원칙

1. 패턴 단독으로 메일을 만들지 않는다.
2. YouTube 후보: BULL 패턴은 BUY_CANDIDATE/JEV의 보조근거, BEAR 패턴은 추격매수 경계 근거.
3. 보유종목: BEAR 패턴은 45분 OBV/MACD 약화·REGIME BEAR와 함께 방어 판단 보조근거.
4. 첫 단계는 SHADOW. 최소 20~30건 결과를 쌓은 뒤 실제 가점/감점 또는 gate 승격 여부를 결정한다.
5. 패턴이 없으면 NONE이 정상이다. 억지로 8종 중 하나를 부여하지 않는다.

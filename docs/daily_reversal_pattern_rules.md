# 일봉 추세전환 8패턴 자동화 규칙 v1

> 목적: 단독 매수·매도 신호는 아니지만 기존 Pullback/ATR/Freshness/수급/45분/JEV 판단을 보강하고, 조건 충족 시 기존 신호를 직접 1단계 조정한다.
>
> 원전 규칙: 사용자가 제공한 「박재훈의 투자농장 - 100조 운용역이 신입 펀드매니저에게 가르쳤던 차트 패턴 8가지」 요약.
> 아래 수치화 기준 중 '장대/단봉/현저한 갭/확연히'는 자동화를 위해 추가한 엔지니어링 정의이며 영상의 직접 수치가 아니다.

## 공통 선행추세

| 구분 | 자동화 조건 |
|---|---|
| 상승반전 4종 | 패턴 1일차 직전까지 SMA3가 5회 연속 하락 |
| 하락반전 4종 | 패턴 1일차 직전까지 SMA3가 5회 연속 상승 |
| 데이터 | 완성된 일봉만 사용. 장중 미완성 당일봉은 제외 |
| 장대봉 | 몸통 >= max(최근 20일 몸통 중앙값 × 1.25, ATR14 × 0.45) |
| 단봉 | 몸통 <= min(최근 20일 몸통 중앙값 × 0.75, ATR14 × 0.45) |
| 유효 갭 | ATR14 × 0.15 이상 |
| Star 비도지 | 몸통 > ATR14 × 0.03 |
| '확연히' 확인폭 | ATR14 × 0.15 이상 |

## 8개 패턴

| Bias | 코드 | 표시명 | 자동화 조건 |
|---|---|---|---|
| BULL | BULL_THREE_RED_SOLDIERS | 적삼병 | 3일 연속 양봉, 2·3일차 시가가 전일 몸통 안, 3일차 종가가 3일 중 최고 |
| BULL | BULL_HARAMI_CONFIRMED | 상승 잉태 확인형 | 1일차 장대음봉, 2일차 단봉이 1일차 몸통 안, 3일차 장대양봉 종가 > 1일차 시가 |
| BULL | BULL_ENGULFING_CONFIRMED | 상승 장악 확인형 | 1일차 단봉 음봉, 2일차 낮은 시가의 장대양봉이 1일차 몸통 장악, 3일차 장대양봉 종가 > 2일차 종가 |
| BULL | MORNING_STAR | 샛별형 | 1일차 장대음봉, 2일차 유효 갭하락 단봉·비도지, 3일차 갭상승 양봉 종가 >= 1일차 몸통 50% |
| BEAR | BEAR_THREE_BLACK_CROWS | 흑삼병 | 3일 연속 음봉, 2·3일차 시가가 전일 몸통 안, 3일차 종가가 3일 중 최저 |
| BEAR | BEAR_HARAMI_CONFIRMED | 하락 잉태 확인형 | 1일차 장대양봉, 2일차 단봉이 1일차 몸통 안, 3일차 장대음봉 종가 < 1일차 시가 |
| BEAR | BEAR_ENGULFING_CONFIRMED | 하락 장악 확인형 | 1일차 단봉 양봉, 2일차 높은 시가의 장대음봉이 1일차 몸통 장악, 3일차 음봉 종가가 2일차보다 최소 0.15ATR 낮음 |
| BEAR | EVENING_STAR | 석별형 | 1일차 장대양봉, 2일차 유효 갭상승 단봉·비도지, 3일차 갭하락 음봉 종가 <= 1일차 몸통 50% |

## 운용 원칙

1. 패턴 단독으로 새 메일을 만들지는 않는다.
2. YouTube 후보: BULL + 0.6ATR + 45분 상승확인 + 수급 NEUTRAL이면 △→▲ 직접 승격 가능.
3. YouTube 후보: BEAR이면 ▲→△, △→관찰로 직접 1단계 강등한다.
4. 보유종목: BEAR 패턴은 REGIME BEAR 조건에서 45분 약세 확정 전에도 매도 대비 경고를 직접 만들 수 있다. 45분 약세와 동시 확인되면 경고 문구를 강화한다.
5. 과열상한, Freshness 훼손, +0.6ATR, 45분 상승확인 등 기존 하드 조건은 상승패턴이 우회하지 못한다.
6. 패턴이 없으면 NONE이 정상이다. 억지로 8종 중 하나를 부여하지 않는다.

# Auto Approval & Autonomous Execution Rule

- **Non-Interactive Execution**: Do NOT use `ask_question` or present multiple-choice modal prompts to the user.
- **Automatic Option Selection**: Always select the best, recommended option automatically and proceed with execution.
- **Continuous Progress**: Process all file edits, script updates, database updates, and command executions autonomously without waiting for explicit permission at every sub-step.
- **Concise Reporting**: Report progress and results cleanly via text messages and update the walkthrough artifact upon completion.
